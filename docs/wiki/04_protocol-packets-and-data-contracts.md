## Packet Envelope and Framing

`firmware/include/protocol.h` is the wire-format authority, while the current strategy document explains runtime policy around that format. Compact UWB wake, discovery, schedule, DS-TWR, and outer mesh frames keep their fixed UWB layouts; reports, commands, survey records, routed payloads, acknowledgements, and errors use the shared IMEC packet envelope ([UWB+BLE Protocols and Strategies 0.3.12.4.md:1-18](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L1-L18), [UWB+BLE Protocols and Strategies 0.3.12.4.md:34-72](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L34-L72)). The shared codec accepts only its report, routing, command, survey, and error families, so compact UWB message IDs cannot be mistaken for shared packets ([protocol.c:81-119](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L81-L119)).

### Shared binary envelope

Every multi-byte value is little-endian. Offset 27 selects one of two canonical header forms: payloads below `0xFF` use a 32-byte header, while payloads from 255 through 958 bytes use sentinel `0xFF`, a 16-bit length, and a 34-byte header ([protocol.h:12-26](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L12-L26), [protocol.c:32-78](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L32-L78)).

| Offset | Size | Field | Contract |
| ---: | ---: | --- | --- |
| 0-3 | 4 | Magic, version, type, flags | Magic is `0xC1`, version is `0x01`, and type must belong to the shared namespace ([protocol.h:12-17](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L12-L17), [protocol.c:81-119](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L81-L119)). |
| 4-19 | 16 | Source and destination IDs | Two 64-bit endpoint identities remain in the application envelope ([protocol.c:145-153](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L145-L153)). |
| 20-26 | 7 | Session, sequence, TTL | Session and sender-scoped sequence preserve packet identity; TTL is the relay-decremented forwarding budget ([UWB+BLE Protocols and Strategies 0.3.12.4.md:97-106](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L97-L106), [protocol.h:390-400](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L390-L400)). |
| 27 onward | 1 or 3 | Payload length | One byte represents 0-254; sentinel `0xFF` plus a 16-bit value represents 255-958 ([protocol.c:154-161](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L154-L161)). |
| Header tail | 4 | Message age, ms | The field occupies bytes 28-31 in the standard header or 30-33 in the extended header ([protocol.c:154-161](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L154-L161)). |
| Packet tail | 2 | CRC-16 | CCITT-FALSE starts at `0xFFFF` and uses polynomial `0x1021` over header and payload ([protocol.c:5-30](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L5-L30), [protocol.c:163-169](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L163-L169)). |

Decoding is fail-closed: a short buffer, wrong magic or version, noncanonical extended length, payload above 958 bytes, exact-length mismatch, bad CRC, or unrecognized shared message type fails before a packet is returned ([protocol.c:174-239](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L174-L239)).

### COBS host framing

The standard serial helper encodes a complete shared packet with COBS and appends a zero delimiter. Its decoder requires that delimiter, reverses COBS, validates the whole packet, and only then returns fields; the helper's `PACKET_MAX_LEN` scratch buffer covers the common allocation through a 255-byte payload ([serial_frame.h:13-26](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/serial_frame.h#L13-L26), [serial_frame.c:5-83](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/serial_frame.c#L5-L83)).

The connected gateway uses the same COBS convention for host-written commands and direct standard packets on `PACKET_RX`, and notifies host-bound data on `PACKET_TX`. Mesh-origin records take a different selective 40-byte record header and can retain the full 958-byte payload; ATT chunks are transport pieces, not packet boundaries ([UWB+BLE Protocols and Strategies 0.3.12.4.md:315-333](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L315-L333), [app_gateway_ble_stream.h:14-33](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/app/src/app_gateway_ble_stream.h#L14-L33)).

## Messages, Flags, and TLVs

The message namespace follows the participant-to-research path: compact UWB contact and ranging establish a measurement, reports carry it toward the gateway, mesh messages preserve delivery, commands operate the deployed system, and survey messages establish anchor geometry. Retired values stay reserved, so old captures cannot be reinterpreted as current traffic ([protocol.h:45-102](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L45-L102)).

| Family | Representative wire IDs | What they carry |
| --- | --- | --- |
| Contact and compact UWB | `WAKE_CLAIM` `0x08` through `RANGE_RELEASE` `0x0D`; `POLL` `0x10` through pair result `0x19` | Wake ownership, discovery, schedules, DS-TWR, diagnostics, and the outer mesh carrier ([protocol.h:45-64](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L45-L64)). |
| Participant and device reports | `CLICK_REPORT` `0x20`, `SELF_TEST_REPORT` `0x21`, `ANCHOR_HEARTBEAT` `0x22` | Research measurements, explicit self-test results, and anchor health ([protocol.h:66-68](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L66-L68)). |
| Routing and reliable delivery | `MESH_DATA` `0x30` through `GATEWAY_ROUTE_REQ` `0x3F` | Payload forwarding, hop and gateway ACKs, routes, negotiated events, and busy responses; `0x33` and `0x34` remain reserved ([protocol.h:70-84](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L70-L84)). |
| Commands and collection | `COMMAND` `0x40` through collection EACK `0x45` | Target operations, correlated results, capacity offers and grants, bundles, and final collection acknowledgement ([protocol.h:86-91](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L86-L91)). |
| Survey and host progress | `SURVEY_REACH_REQ` `0x50` through `GATEWAY_COMMAND_EVENT` `0x56` | Reachability, pair control and results, discovery reports, and command-lifecycle telemetry ([protocol.h:93-100](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L93-L100)). |

The flag byte carries independent assertions for control follow-up, route setup, gateway ACK requirements and completion, diagnostic data, counted clicks, errors, and range-only work ([protocol.h:104-113](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L104-L113)). Those semantic flags and the application identity stay immutable across retries and relays; only TTL and message age are forwarding metadata ([UWB+BLE Protocols and Strategies 0.3.12.4.md:74-95](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L74-L95)).

A range packet selects exactly one of counted-click or diagnostic mode, always requests a gateway ACK, starts at TTL 4 and message age zero, and rejects missing identities, a zero session or sequence, or both modes together ([report.c:800-830](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L800-L830)). Its payload validator rejects duplicate known singleton fields, mismatched anchor/source or event/session identity, half-present detection evidence, malformed CIR fragments, misaligned sample arrays, and a counted-click fragment without a nonzero burst ID ([report.c:54-316](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L54-L316)).

### TLV payload model

Each payload field is `type:u8`, `length:u8`, then `length` bytes. Numeric appenders encode little-endian values, so one TLV value is bounded to 255 bytes ([protocol.h:22-26](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L22-L26), [protocol.c:242-302](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L242-L302)). `tlv_find()` can skip an unknown field, but it rejects a missing TLV header or a declared value that overruns the payload; message-specific readers then require exact widths for mandatory fields ([protocol.c:304-418](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L304-L418)). Additive unknown fields are therefore compatible only when the enclosing message's required schema still validates.

## Identity, Correlation, and Time

The protocol carries layered identity so that the [end-to-end click path](02_one-click-end-to-end.md), [mesh delivery path](05_connected-routing-and-reliable-delivery.md), and [survey workflow](07_anchor-self-setup-survey-and-geometry.md) can reject cross-run traffic at their own boundaries. Envelope identity handles packet transport, while application TLVs add the correlation needed for clicks, commands, surveys, and channel-9 connection incarnations ([UWB+BLE Protocols and Strategies 0.3.12.4.md:97-134](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L97-L134)).

| Layer | Identity tuple or field | Contract |
| --- | --- | --- |
| Shared packet | `src_id`, `dst_id`, nonzero `session_id`, `seq`, semantic flags, exact payload | One logical request keeps these values across deferrals and retries; relays may change only TTL and message age ([UWB+BLE Protocols and Strategies 0.3.12.4.md:97-116](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L97-L116), [protocol.h:390-400](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L390-L400)). |
| Counted range fragment | `clicker_id`, `anchor_id`, `event_seq`, nonzero `burst_id`, sample count/index, aligned distance, round, and timestamp arrays | Anchor ID must equal packet source, event sequence must equal packet session, and every counted-click range fragment must include aligned samples and a burst ID ([report.c:265-316](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L265-L316)). |
| Command result | `gateway_id`, `gateway_epoch`, `command_seq`, `node_id`, `node_boot_counter`, `result_seq` | The composite separates gateway generations, commands, node reboots, and repeated results instead of treating one sequence as globally unique ([protocol.h:402-409](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L402-L409), [protocol.c:420-483](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L420-L483)). |
| Broadcast survey command | Envelope source and destination, mandatory nonzero `COMMAND_SEQ`, survey session, and `SURVEY_ROUND_ID` | Command sequence distinguishes later GO rounds inside one survey session; the round ID rejects stale work from another synchronized round ([UWB+BLE Protocols and Strategies 0.3.12.4.md:118-122](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L118-L122), [UWB+BLE Protocols and Strategies 0.3.12.4.md:272-313](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L272-L313)). |
| Channel-9 event owner | PROPOSE session, independent local and remote control sequences, and nonzero per-boot `MESH_EVENT_BOOT_NONCE` | A reboot starts a new incarnation without making delayed pre-reset proposals current again ([UWB+BLE Protocols and Strategies 0.3.12.4.md:124-130](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L124-L130)). |

Exact duplicates are idempotent and ACK-sticky: the receiver does not repeat the semantic mutation, but it acknowledges the same request again so a lost ACK can be repaired. Reusing one identity with different flags, length, or payload is a conflict and fails closed ([UWB+BLE Protocols and Strategies 0.3.12.4.md:110-116](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L110-L116)).

Time has two distinct representations. `message_age_ms` is envelope forwarding metadata, while `TIMESTAMP_MS` and sequence-start timestamp arrays live in the application payload; consumers must not substitute one for the other when correlating samples ([protocol.h:390-400](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L390-L400), [report.c:127-185](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L127-L185)). The packet CRC detects corruption but provides no keyed authentication, so node IDs and route evidence cannot be treated as hostile-RF proof of identity ([UWB+BLE Protocols and Strategies 0.3.12.4.md:132-134](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L132-L134)).

## Capacity and Compatibility Contracts

Packet capacity is a cross-role contract. The generic codec supports a 958-byte extended payload, but queues and transports deliberately admit smaller or more specialized sets; codec capacity alone does not prove end-to-end admission.

| Boundary | Enforced capacity | Consequence |
| --- | ---: | --- |
| Standard shared header | 0-254 payload bytes, 32-byte header | Payload `0xFF` is the extended-length sentinel, so 255 bytes must use the canonical 34-byte form ([protocol.h:14-21](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L14-L21), [protocol.c:71-78](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L71-L78)). |
| Common packet allocation | 255 payload bytes; 291 bytes including header and CRC | The COBS helper uses this allocation, so larger packets fail capacity checks rather than truncate ([protocol.h:18-21](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L18-L21), [serial_frame.c:5-40](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/serial_frame.c#L5-L40)). |
| Extended shared packet | 958 payload bytes; 994 bytes with header and CRC | The core encoder and decoder reject a larger packet ([protocol.h:20-21](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/protocol.h#L20-L21), [protocol.c:121-142](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L121-L142)). |
| One extended UWB mesh frame | 1,021 bytes before the 2-byte PHY FCS; 1,023 bytes including it | Compile-time arithmetic requires the complete 994-byte shared packet to fit behind the 25-byte mesh header and 2-byte mesh CRC ([uwb.h:119-131](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/uwb.h#L119-L131)). |
| Production communication ownership | Four delivery slots, one reserved for protocol work; 192 frozen payload bytes | Ordinary accepted deliveries remain within a bounded RAM footprint; only the synthetic transmitter raises its frozen payload ceiling to 958 bytes and adds one stress slot ([app_node_comm.h:11-28](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/app/src/app_node_comm.h#L11-L28)). |
| Gateway oversized-control owner | One bounded-control-flood payload through 958 bytes | Only the gateway admits this specialized oversized owner, and a second payload is rejected while it is occupied ([app_node_comm.c:309-323](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/app/src/app_node_comm.c#L309-L323), [app_node_comm.c:431-479](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/app/src/app_node_comm.c#L431-L479)). |
| Gateway collection EACK | 57 fixed bytes; 557 bytes at the 50-node maximum | Static assertions bind the computed EACK to the extended-packet ceiling ([gateway_command.h:15-35](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/gateway_command.h#L15-L35), [gateway_command.h:226-230](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/gateway_command.h#L226-L230)). |
| Gateway BLE record | 958 payload bytes behind a 40-byte record header; queue depth 3; 1,756-byte pool | Full record support still has bounded queue and pool ownership, with a separate 2,048-byte RAM budget ([app_gateway_ble_stream.h:14-33](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/app/src/app_gateway_ble_stream.h#L14-L33)). |
| One click range aggregate | 96 samples total; at most 13 aligned samples per packet | Larger aggregates are chunked by sample count and index; a diagnostic CIR window is 1,152 raw bytes with an 881-byte first chunk and bounded remainder ([report.h:13-29](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/include/report.h#L13-L29)). |

Compatibility fails closed at each boundary. The fixed envelope version must match, retired message IDs remain unavailable, an extended length below 255 is noncanonical, required fields need exact widths, and known singleton click TLVs cannot repeat ([protocol.c:174-239](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L174-L239), [protocol.c:304-418](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/protocol.c#L304-L418), [report.c:54-316](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L54-L316)). Unknown additive TLVs remain skippable, while paired optional detection fields must appear together and every counted-click range fragment must carry a nonzero burst ID ([report.c:265-316](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/firmware/src/report.c#L265-L316)).

Gateway acceptance is also a capacity boundary. For host-visible clicks, command results, bundles, and survey results, the gateway validates semantics, reserves the complete host record, commits required durable state, and commits stream admission before sending the gateway ACK or completion response. Malformed, stale, queue-full, or persistence-failed work remains upstream and retryable because it was never accepted ([UWB+BLE Protocols and Strategies 0.3.12.4.md:201-239](https://github.com/Jubliano-sama/IMEC2/blob/c9e8e2fe4a450a8d65f697ce026f8524c81b105f/Documentation/UWB%2BBLE%20Protocols%20and%20Strategies%200.3.12.4.md#L201-L239)).
