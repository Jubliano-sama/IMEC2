# Agent Known Issues Summary

This is a curated bug log: each entry records an observed failure, its cause, and its fix, workaround, or unresolved status. Entries are historical evidence, not requirements or design rules.
The append-only `AGENT_KNOWN_ISSUES.md` is canonical and receives all new entries; this summary is periodically rebuilt with much greater weight on recent incidents.

## Older Recurring Incidents

- Fixed transactional soft-reset candidates inheriting an unfeedable running nRF watchdog by adopting and immediately feeding every enabled reload request, then clearing the captured RESETREAS latch; root cause was Zephyr resetting its nrfx software state while the nRF WDT peripheral and cumulative reset-cause bits deliberately survive a CPU reset.
- A freshly mass-erased mesh anchor can fail verified-flash full-image readback with exact HEX bytes intact because startup initializes five bytes in non-code persistence sector 122; compare code bytes before diagnosing corruption, then rerun from the stable persistence baseline.
- Fixed route-reply listeners consuming standard-PHR click claims as route contact or PHY errors without handing them to the click sequence; extended listeners now trigger one bounded standard-PHR probe on incompatible activity, and the simulator records same-channel PHY mismatches as activity/decode failures.
